👾 100 个 VibeCoding 项目之 AI 接管小红书

更新于2026 11 02|项目VibeCoding

⚠️ 声明：本篇的文字、配图、编辑和发布，全部由 AI 完成。

小红书发布那一步太碎：选图、想标签、挑时间、点发布，每次都要重来一遍。

我想把这一步交出去，于是给自己加了一层 Web 后台，底座接一个开源的 MCP。后台是我写的，一条 ./start.sh 起来，浏览器打开 http://localhost:3721 就能用，不写配置也能跑；MCP 是 xiaohongshu-mcp，把小红书网页端包成 13 个工具。合起来是一条流水线：AI 写、AI 配图、定时或 Webhook 触发、发完回看结果。

下面按后台的六块走一遍，每块一张图，最后说边界。

🖥️ 今天发了几篇

仪表板上是发布热力图、发布数、运行中的任务、粉丝与获赞。任务列表每条前面有个开关，关掉就不再自动跑。界面有亮色、暗色、跟随系统三种。

仪表板只回答一个问题：今天发了没有。

🗓️ 三种触发

新建任务时选手动、定时还是 Webhook。

定时是可视化的 Cron，填「每天 21:00」，底下实时预览下次执行时间。Webhook 保存后生成 http://localhost:3721/api/webhook/<token>，往这个地址发一个 POST 就触发一次。任务能立即执行、暂停、编辑、删除，不用改代码。

编辑任务时可以写提示词，也能指定要扫描的本地项目工作区。

✍️ 文字和图都交给 AI

任务里那段提示词是给 Claude 的：执行时它按提示词生成标题、正文和话题标签。

配图两条路：从本地图片目录随机取一张，或者对话式生成，模型在 FLUX 1.1 Pro、FLUX Dev、SD 3.5 之间自己选。

两个 Key 在设置页填：Anthropic 管文字，Replicate 管图。填完能一键测连通性。

配错也不用翻日志，发布历史里会直接写 401 invalid x-api-key。

🕘 发完看历史

每次执行留一条：标题、状态、失败原因。

失败原因写得很直白：401 是 Key 不对，超时是浏览器那头没等到。任务、历史、Profile 缓存都存在 frontend/data 的 JSON 里，翻起来比日志快。

🔌 底座只有一个 MCP

xiaohongshu-mcp 把小红书网页端包成 13 个工具：

登录状态、登录二维码、清 cookie、发图文、发视频、首页推荐、搜索、帖子详情、发评论、回复评论、点赞、收藏、个人主页。

接上 Claude Code、Cursor、Cline，告诉它要做什么就行。

发图文那个工具的参数值得单独说：

  • images：支持 HTTP 链接和本地绝对路径，本地更稳，上限 9 张、单张 20MB
  • tags：话题标签数组
  • schedule_at：能排到一小时之后、十四天以内
  • visibility：公开可见、仅自己可见、仅互关好友可见
  • is_original：声明原创

视频那个工具只收本地绝对路径，上限 500MB。

一句话分工：MCP 是手，后台是台面。台面把顺序排好，手负责点下去。

📌 我给它定的规矩

标题 20 个字，正文 1000 个字，开头一句要抓人，结尾不硬求赞。

语气按我说话的样子来：不长篇大论，不堆术语，不喊口号。

封面也定死了：真人出镜、手写标题、系列名不变。字让图像模型直接写进画面，不做本地字体排版。

标签先用 xhs-smart-tags 那个技能筛到 5–8 个，再塞进 MCP 的 tags 参数——CDP 那条发布流程本身不收话题。

📦 素材从哪来

  • 封面和配图：本地图片目录随机取，或者 FLUX、SD 生成
  • NAS：挂成 SMB/WebDAV 目录，填进图片目录就行
  • GitHub：每天 21:00 有个「AI 开发日报」任务，扫各仓库当天的 git log，交给 Claude 写成文案再发
  • Profile：每天 20:00 同步一次，粉丝和获赞是这么来的

🍃 发一篇是什么感觉

对 AI 说一句：发一篇关于春天的，用这张图。

它自己挑工具、填标签、点发布。或者放进定时任务，晚上九点自己发。

🚧 边界

  • 不是官方接口，走的是网页端。网页一改版，工具就要跟着修
  • 一个账号不能同时在多个网页端登录
  • 别做引流和搬运
  • 偶尔发一两篇，手动更快

11 月 1 日发飞书那篇笔记时，新版创作中心就补了三处：离屏标签页的副本被误判成遮挡、标题回点卡住、标签和发布按钮的元素点击超时。不补就点不到按钮。

省下来的是发布前那几十下：打开 App、上传图片、填标签、点发布。

写，还是得自己来。

🌙 收尾

这是 100 个 vibecoding 项目里的一个。它没让我少写一个字，只是把发布那一步接了过去。
